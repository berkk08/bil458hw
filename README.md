# 📝 String to Long Conversion (bil458.py)

## 📌 Açıklama
Bu program, kullanıcıdan **string olarak girilen bir sayıyı** alıp **long (Python'da int) türüne çevirir.**  
Eğer geçerli bir sayı girilmezse, kullanıcıya hata mesajı verir.
